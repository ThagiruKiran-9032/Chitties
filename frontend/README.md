# Chitties Frontend Client

Modern, responsive web interface for Chitties Chit Fund Management platform.

## Stack
- **Framework**: React 18
- **Tooling**: Vite 6
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM 6
- **Icons**: Lucide React
- **HTTP Client**: Axios

## Setup & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
